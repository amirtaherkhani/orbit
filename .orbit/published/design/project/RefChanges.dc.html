Change list

The single list of what the fork changes in Grafana: replaced, hidden and added parts. Read it before building anything; if a part is not here, use Grafana as is. New parts are described in detail on R02 · New features (not in Grafana).

Rule. Every part of Grafana that is not listed on this board stays exactly as Grafana ships it: layout, components, styles, copy and behaviour. Decided by the owner on 2026-11-02. When a new change is agreed, add it here first; anything missing from this board is a Grafana default.
