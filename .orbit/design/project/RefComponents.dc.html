Component catalog

Every shared component of the custom UI, with its contract: props, states, events and keys, data, and what it uses. Each screen board drew its own copy of a component and its own behaviour; here they are merged into one component each, so agents can build them one by one and the prototype can put them together. Source: .orbit/design/components.json (the same data, for agents). Names follow R03; code paths follow ARCHITECTURE.md section 8.

How they fit together

The shell is always on screen; overlays open from it one at a time; views fill the page inside the shell. Four hooks hold the shared state, so a click in one component changes the others: useActiveApp, useBookmarks, useApps, useOverlay.

Specified

Props app: App · pages: Page[] the user may open · page: index of the current rail row · focus: index of the focused tile · loading: boolean · canSetup: boolean, the user may continue the app's setup

States Section with sub pages (S07) · Section without sub pages: the page is its own tile (S02) · Group tabs (S10) · App dropdown open (S14) · Another app selected, loading skeleton (S19) · App with no pages: 'No pages yet' and Continue setup, the button only for users who may set it up (N10) · Sub pages not available

Events and keys

  • Rail row → shows its sub pages
  • Tile click → opens the page, closes the sheet, focus returns to Menu (N8, N9)
  • Open <page> → opens the page, closes the sheet
  • Bookmark toggle → adds or removes the bookmark at once
  • Bookmarks → opens DockPagesView (/bookmarks)
  • Click outside → closes the sheet, focus returns to Menu (N8)
  • Picking another app → loads its pages with a skeleton; Monitoring never shows loading (N6)
  • Arrow keys move focus between tiles; they never open (N9)
  • Enter opens the focused tile
  • B toggles the bookmark of the focused tile, not while typing
  • Esc closes the sheet and returns focus to Menu; stop propagation so Grafana's own Esc does not also run (R08)

Data useActiveApp · useApps (pages from the nav tree or app includes) · useBookmarks

Uses OverlaySurface · AppSwitcher · PageTile · CardToggle · FilterTabs

Open Tab order: rail first or tiles first (R08) · Group tab names: 'Access' or Grafana's 'Users and access' (R08, decision needed)
