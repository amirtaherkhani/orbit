Tokens

Design values used in the boards, compared with the default dark theme in Grafana v13.3.0 (packages/grafana-data/src/themes). Usage counts and matches are computed from the board CSS, not typed by hand. "Near" means the closest Grafana colour is within 14 RGB units; "Custom" means there is no Grafana token to point at.

Why this matters for the fork. The most used neutrals in the design (#c9cdd3, #9fa7b3, #8d939c) are not Grafana tokens, and the accents (cyan, gold, blue) are not in the theme at all. Decide per row: adopt the Grafana token, or add the value as a custom token. The decision changes how the fork follows upstream theme updates.
