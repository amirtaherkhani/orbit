Foundations

What the Tokens board does not cover: per-app accents, icons, motion, focus, the clock and the basic controls. Values are read from the board CSS and measured in Chromium.

Set on the inner panel as --hac (accent), --hbg (hover and selected fill), --htx (text) through data-app.

Icons

Every icon path in the boards was matched against public/img/icons in Grafana v13.3.0: all come from Grafana’s set (unicons, solid, mono). Only the Grafana logo is separate. For sections and pages the design uses the same icon the nav tree sends, so the fork can render navItem.icon with <Icon />.
