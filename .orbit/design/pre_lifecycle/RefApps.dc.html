Apps and dock pages

Two views with one pattern: a filtered card grid and a preview panel. Add app decides where an app appears (menu, dock selector). Add a bookmark bookmarks pages and sub pages; an app itself and the tabs inside a page are not bookmarks. Specimens are real markup from the D boards.

Open, the expander lists the sub pages as rows inside the card, 34 high: icon tile 20, name, path relative to the page (“…/weekly”), In dock icon, Open and pen on hover or when selected, and the same bookmark toggle at 22. Clicking a row selects that sub page in the Page panel. Nested sub pages (Administration) show under small group labels (General, Plugins and data, Access). Clicking a card selects it and opens the Details tab of the Page panel for that page. The icons on the card do not select it: Open opens the page, the pen opens Edit bookmark, the bookmark icon only toggles. There is no separate “show details” icon. Its icon row, left to right: Open (Grafana external-link-alt, the same icon as “Open <section>” in the MenuSheet header), pen (Edit bookmark: selects the page and opens Edit bookmark; the pen sits on an accent fill while that card is edited), bookmark toggle. Cards are grouped under an app header (accent bar, name, “n pages · n bookmarked · n of 6 in the dock”) with an Open <app> button in the MenuSheet style (secondary, label + external-link-alt) that opens the app’s home page (its defaultNav page; Home for Monitoring). Footer outside the tabs: Details shows only Edit (no bookmark button: the bookmark toggle on the card or row does the same, decided 2026-11-06); Edit bookmark shows Reset to default, Cancel and Save

TopicDesignStatusNote
What can be bookmarkedPages and sub pages, each with its own toggle. Not the app (Open <app> opens its home), not tabs inside a pageVerified in v13.3.0Grafana offers the bookmark on any nav item with a URL (MegaMenuItem.tsx), at any depth; tabs come from pageNav and are not nav items. Sub pages of an app come from includes nested by path (grafana.pluginPathNesting, experimental, off by default)
Which apps are listedInitialized apps with a manifestNot verifiedHow “initialized” is detected is open on the manifest board. Grafana lists app plugins as nav sections plugin-page-<id>
Where a choice is storedPer user or per organisationDecision neededDecides whether everyone sees the same dock. Bookmarks in Grafana are per-user preferences (navbar.bookmarkUrls)
Home in the dock“Home is always there.”Custom specifiedThe app home (its defaultNav page) is always in the dock, so it is not offered as a bookmark

Grafana’s data and API stay as they are. Which pages are bookmarked is Grafana’s list; everything we add is derived from the URL or kept per user in Grafana’s existing user storage.
